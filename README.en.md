# Velin

**A lightweight Minecraft Java launcher for Windows, with a medieval look.**

[Español](README.md) · [Download](https://github.com/Brhenja/Velin/releases) · [Report an issue](https://github.com/Brhenja/Velin/issues)

Velin is a Minecraft Java launcher written in **C# / .NET 8 / WinForms**. Every instance lives in its own folder,
Java is downloaded for you, Fabric, Forge, Quilt and NeoForge are installed automatically, and you can search mods,
modpacks, resource packs and shaders on **Modrinth** and **CurseForge** from the same interface.

> **Disclaimer:** Velin is an independent project. **It is not affiliated with, associated with or endorsed by Mojang
> Studios or Microsoft.** Minecraft is a trademark of Mojang Studios.

> **How it was made:** most of this project was **"vibe-coded"**. The ideas, design and direction are Brhenja's; the
> code was written by **Claude**, Anthropic's AI. The assets (music, click sound, Flash theme mascot and icon) were
> also generated by an AI.

## What's new in 1.1.1

- **Search pages:** results for mods, modpacks, resource packs, shaders and datapacks can be browsed with
  **◀ Previous / Next ▶** (you used to see only the first 30).
- **Skin manager** (in **Accounts → Skins...**): current skin of a Microsoft account, upload a `.png` and change it,
  local skin library (Classic or Slim model), 2D front/back preview, and restore the default skin. The account's skin
  face is shown in the main window.
- **Offline accounts:** Mojang has no skins for them; Velin copies the skin into the instance in the format used by the
  [CustomSkinLoader](https://modrinth.com/mod/customskinloader) mod, which must be installed in that instance.
- **Mod details:** the icon is no longer black when it is `.webp`/`.svg` (the original or a letter is used), link buttons
  fit their text, and gallery images can be viewed in full with a click.

## Status

- **Microsoft login:** the full flow against the real Microsoft/Xbox/Mojang servers has had only limited testing; if
  something fails, open an [issue](https://github.com/Brhenja/Velin/issues) with the message Velin shows.
- **CurseForge and NeoForge 1.20.1** are implemented but **have not been tested against the real servers yet**.
- **GraalVM and Semeru** are downloaded from the official sources (Oracle and IBM's GitHub); downloading and starting
  Minecraft with them may need adjustments.
- The installer is **not code-signed**: Windows SmartScreen may show a warning ("Windows protected your PC").
  You can continue with *More info → Run anyway*.

## Requirements

- Windows 10 or 11, **64-bit**.
- Internet connection to download Minecraft, Java and content.
- You do not need to install .NET or Java: the installer includes .NET and Velin downloads the Java each version needs.

## Installation

Get what you prefer from the [Releases](https://github.com/Brhenja/Velin/releases) page:

**Installer (`VelinSetup-1.1.1.exe`)**
1. Run it. It does not ask for administrator rights: it installs to `%LocalAppData%\Velin`.
2. Choose whether you want a desktop shortcut and finish. It is also added to the Start menu.
3. To uninstall: *Windows Settings → Apps*. It asks whether you also want to delete your data (instances and
   worlds); **by default they are kept**.

**Portable (`Velin-1.1.1-portable-win-x64.zip`)**
1. Extract it to a folder your user can write to (not `Program Files`).
2. Run `Velin.exe`. To remove it, delete the folder.

Data is stored in the `data\` folder next to the `.exe`, so you can move the folder and take everything with you.

## Usage

**First run**
1. Click **New instance** (`Ctrl+N`): pick a name, Minecraft version, mod loader (or Vanilla) and RAM.
2. Click **Play** (`Enter`). The first time it downloads everything (Java, libraries and assets) with a progress bar
   and a **Cancel** button; after that it starts right away.
3. If Minecraft exits with an error, a window shows the last log lines with buttons to open the full log, the crash
   report or copy the text.

**Mods and content**
- The **Mods and content** button opens a per-instance panel with mods, modpacks, worlds, servers, resource packs,
  shaders, datapacks, screenshots, backups and console.
- Pick the source at the top left: **Modrinth** or **CurseForge** (datapacks are Modrinth only). The one shown first
  is set in **Settings → Content**.
- **Details:** the **Details** button (or double-clicking a result or an installed mod) opens a window with the
  project's description, image gallery and official links. It is drawn with native Windows controls: no extra
  dependencies and no embedded browser. Images are cached in `data\cache\img`; `.webp` images cannot be shown by
  Windows and are skipped.
- With no instances, **Mods and content** stays enabled and offers to create one.
- Installing a mod also installs its **required dependencies**, without duplicating what you already have.
- **Check mod updates** looks at both sources and downloads the new version before removing the old one.

**Accounts**
- In **Accounts** you create offline accounts (any name) and choose a default one or one per instance.
- From **Accounts** you can **sign in with Microsoft** (your browser opens; the session is stored encrypted with DPAPI
  and renews itself) or create offline accounts (any name). Pick a default one or one per instance.
- **Skins...** opens the skin manager for the chosen account (see above). The library lives in `data\skins`.

**Custom .jar**
1. Create a folder inside `data\instances\` (for example `data\instances\My client`).
2. Put a client `.jar` inside it.
3. Open Velin (or reload with `F5`): the folder shows up as an instance marked "jar propio" (custom jar). If the
   `.jar` does not declare its version (anything older than 1.14), Velin asks for it the first time you play.

**CurseForge API key**
CurseForge requires a personal key. Velin ships none: get a free one at
[console.curseforge.com](https://console.curseforge.com) and paste it in **Settings**. It is stored only on your PC.
Without a key, Modrinth keeps working as usual.

**Shortcuts:** `Ctrl+N` new instance · `Ctrl+I` import · `F5` reload · `F2` rename · `Del` delete · `Enter` play.

## Features

**Instances**
- Each one has its own folder (`versions`, `mods`, `saves`, etc.): create, duplicate, rename and delete.
- Export and import: Velin `.zip`, Modrinth `.mrpack` and CurseForge `.zip`.
- Groups with a filter, sorting by name / last played / play time, and play time per instance.
- Change an instance's version or loader while keeping worlds, mods and settings.
- Instances with a **custom .jar**.

**Loaders:** Vanilla, Fabric, Forge, Quilt and NeoForge (including 1.20.1). The list only shows compatible versions
and picks the newest stable one by default.

**Java and launching**
- **Temurin** Java downloaded automatically for each Minecraft version, detection of other installed Javas
  (including GraalVM and Semeru, with the vendor shown in the list), and a custom Java per instance.
- **Optional Java runtimes** (not bundled with Velin): in **Settings → Java** you download and enable **GraalVM 21**
  and/or **IBM Semeru (OpenJ9)** 8/17/21. Once enabled, pick which one to use in each instance's **Launch options**.
  If the chosen Java does not fit that Minecraft version, Velin warns you and uses Temurin.
- Aikar-style (G1) JVM flags for HotSpot and GraalVM, and dedicated flags for OpenJ9 (`gencon` + shared class cache);
  they can be turned off and global arguments added in **Settings → Game**. Fixed RAM per instance (with a warning if
  there is not enough).
- Per-instance options: window or fullscreen, join a server or world directly, extra arguments.
- Verified downloads (SHA1 and size, retries, no half-written files).
- `velin-launch.log`, live console and an option to keep the launcher open while you play.

**Content**
- Mods (enable/disable, remove, update), modpacks (with version selection), resource packs, shaders and datapacks.
- Hash-based recognition of local `.jar` files (Modrinth).
- **Worlds:** back up one, duplicate, delete, export and import `.zip`.
- Optional **automatic backups** with restore from the interface.
- **Servers:** list with live status and direct join.
- **Screenshots** with thumbnails.
- **Vault:** built-in file explorer with subfolders, drag and drop, cut/copy/paste and extraction of `.zip`, `.7z` and
  `.rar`; plus a per-instance mods Vault.

**Interface**
- Custom borderless window, JSON themes (medieval Velin, Flash and **Black & White** dark and light), Spanish and English.
- Background music (with a switch and volume) and click sound, optional skippable splash screen.
- **Settings** in sections: language, theme, username, confirmations, RAM, global JVM flags/arguments, optional Java
  runtimes, content source and API key, sound, proxy, data folder and cache cleanup.
- Optional proxy (the game uses it too).

## Custom themes

Themes are `.json` files. The built-in ones are in `Assets\Themes\`. To make your own, copy one, change its name and
colors (hex codes) and save it in `data\themes\` (the folder is created the first time you open Velin). It shows up in
**Settings → Theme**, and the theme **changes without restarting** (changing the language, on the other hand, does ask
for a restart).

```json
{
  "Name": "My Theme",
  "BgDark": "#112233",
  "BgLight": "#223344",
  "ControlBg": "#334455",
  "ControlText": "#FFFFFF",
  "InputBg": "#EEEEEE",
  "InputText": "#112233",
  "Accent": "#FF8800",
  "ButtonTextOnAccent": "#000000",
  "TitleBarBg": "#0A1522",
  "TitleBarText": "#FFFFFF",
  "ProgressBarColor": "#FF8800",
  "ButtonGradientTop": "#445566",
  "ButtonGradientBottom": "#223344",
  "UseMedievalFont": false
}
```

## Where your data lives

Everything is in `data\` next to the `.exe` (with the installer: `%LocalAppData%\Velin\data`):

```
data\
  instances\   your instances (worlds, mods, settings)
  java\        downloaded Java
  libraries\   Minecraft libraries and assets
  assets\
  cache\       image cache for mod details
  skins\       your skin library
  vault\       your personal Vault
  themes\      your JSON themes
  backups\     world backups
  settings.json
  accounts.json   (tokens encrypted with DPAPI)
```

Updating Velin with the installer **does not touch** `data\`.
